wistribute

A single self-contained Win64 .exe that downloads ZeroBraneStudio's master.zip and extracts it locally — with an optional Win32 GUI. No DLLs, no installer, no sidecar files.

Two binaries from one source tree
ExeModeWhat it does
wistribute.exeDOWNLOAD Fetches the zip at runtime via WinHTTP, then extracts.
wistribute-offline.exeEMBEDDED Zip baked into the exe via C23 #embed. Fully offline.

Stack

  • C23 (mingw-w64 GCC ≥ 15 — needed for #embed)
  • WinHTTP for HTTPS (TLS via Schannel) — no libcurl, no OpenSSL
  • miniz (vendored at build time) for ZIP extraction
  • Win32 for the GUI (msctls_progress32 + IFileOpenDialog)

Tested binary sizes

BinarySizeExternal DLLs required
