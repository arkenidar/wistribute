wistribute Overview Build Usage Architecture Plans

Usage

One exe, two surfaces. Double-click for a GUI; run from a shell for CLI output.

Synopsis

wistribute.exe [--cli] [--gui] [--out DIR] [--url URL] [-h|--help]

Flags

FlagEffect
--cliForce CLI mode even when no console is attached
--guiForce the GUI window even from a console
--out DIRExtraction destination (default: current working directory)
--url URLOverride the download URL (DOWNLOAD build only)
-h, --helpPrint usage and exit

Mode selection

The exe decides between CLI and GUI based on how it was launched:

Launched fromDefault mode
Double-click in ExplorerGUI
cmd.exe / PowerShell / shellCLI
With --cliCLI (always)
With --guiGUI (always)

When invoked from a shell, the exe re-attaches to the parent console via AttachConsole(ATTACH_PARENT_PROCESS) so progress and errors appear inline, not in a popped-up window.

CLI

Progress is printed to stderr as a percentage / byte count that updates in place via carriage return:

> wistribute.exe --cli --out C:\tmp\zbs
download  87%  (4194304 / 4823211)
extract   100%  (1842 / 1842)
done. extracted to C:\tmp\zbs

Exit code 0 on success, non-zero (Win32 error code or miniz error) on failure.

GUI

The window contains:

  • URL field (read-only and labelled (embedded payload) in offline builds)
  • Output path field + Browse… (modern IFileOpenDialog folder picker)
  • Themed progress bar (Common Controls v6 — comes from the embedded manifest)
  • Status line
  • Start button (default; activatable with Enter)

Completion behaviour

OutcomeWhat changes in the window
Success Status: "Done — you can close this window."
Start relabels to Close; focus moves to it.
Enter or click closes the app.
Failure Status: "Download failed." or "Extraction failed."
Buttons re-enable; user can retry.

Examples

# Download into a specific directory
wistribute.exe --cli --out D:\tools\zbs

# Use a custom mirror
wistribute.exe --cli --url https://my.mirror/zbs.zip --out D:\tools\zbs

# Force the GUI from a shell
wistribute.exe --gui

# Offline build — payload is embedded
wistribute-offline.exe --cli --out D:\tools\zbs
